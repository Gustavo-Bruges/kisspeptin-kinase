Regla de independencia

Las ramas B y C avanzan en paralelo y no comparten resultados hasta D1. Esa separación es la que permite leer la convergencia como evidencia.

Ruta crítica

A1 → A2 → (B1 → B2 → B3 ∥ C1 → C2 → C3) → D1 → D2 → D3. Si C1 no consigue una tercera serie, C y D1 se presentan como exploratorios.
